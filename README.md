# 🦷 Multi-Clinic WhatsApp AI Receptionist

> Production-ready WhatsApp AI chatbot for dental clinics — appointments, FAQs, reminders 24/7.

**Built by SreeniVerse Technologies, Hyderabad**

## 🛠️ Tech Stack
- WhatsApp: Baileys v7
- AI: Google Gemini 2.0 Flash
- Storage: Google Sheets API
- Scheduler: node-cron
- Runtime: Node.js v20 + PM2

## ✨ Features
- AI intent detection (natural language)
- Full appointment booking flow
- Automated 24hr & 1hr reminders
- Multi-clinic support (JSON config)
- Human handoff system
- 24/7 uptime via PM2
